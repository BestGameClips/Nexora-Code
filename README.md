# RustIDE Ultimate - Module 1
Prerequis Windows : Rust (rustup), Node LTS, Build Tools VS (Developpement Desktop en C++).
1. npm install
2. npm run tauri icon chemin\vers\logo.png (genere src-tauri/icons, requis pour compiler)
3. npm run tauri dev puis npm run tauri build
Mode portable : placer un fichier portable.flag a cote de l exe (donnees dans data/).
